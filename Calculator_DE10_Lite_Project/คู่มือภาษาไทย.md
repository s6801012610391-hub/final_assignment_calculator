# คู่มือโครงงานเครื่องคิดเลข VHDL สำหรับบอร์ด DE10-Lite

## ไฟล์ที่ใช้เปิดโปรเจกต์

ดับเบิลคลิกหรือเปิดจาก Quartus Prime Lite: `Calculator_DE10_Lite.qpf`

บอร์ดที่ตั้งไว้คือ Terasic DE10-Lite (MAX10 หมายเลข `10M50DAF484C7G`) สัญญาณ CLOCK_50 = 50 MHz

## วิธีใช้บนบอร์ด

- **KEY0**: Reset เมื่อกดปุ่ม (Active-Low) กลับไปแสดง SELECT และ DONE=0
- **KEY1**: กดและปล่อยหนึ่งครั้ง = ไปขั้นตอนถัดไป (วงจร Debounce แล้ว)
- **SW9..SW0**: เลข signed 10 บิต แบบ two's complement ตั้งค่าได้ -512 ถึง +511
- **SW1..SW0**: เลือก Operation ตามตารางด้านล่างในขั้นตอนเลือก OP
- **LEDR0**: DONE=1 เมื่อคำนวณเสร็จ แม้พบ Error

| SW1 SW0 | ผลลัพธ์ |
|---|---|
| 11 | A+B |
| 10 | A-B |
| 01 | A×B |
| 00 | A÷B |

ขั้นตอน: Reset → (KEY1) แสดง A → ตั้ง A แล้ว (KEY1) บันทึก A → (KEY1) แสดงรูปแบบ Operation → ตั้ง SW1 SW0 แล้ว (KEY1) บันทึก Operation → (KEY1) แสดง B → ตั้ง B แล้ว (KEY1) บันทึก B → คำนวณและแสดงผล

เมื่อได้ผลลัพธ์แล้วจะอยู่สถานะ RESULT/ERROR จนกด KEY0 เท่านั้น

**ข้อจำกัดการแสดงผล:** 7-segment มี 6 หลัก HEX5..HEX0 โดย HEX0 อยู่ทางขวาสุด, active-low. บวก/ลบ/คูณใช้ HEX5 เป็นสัญลักษณ์การคำนวณ ถ้าผลติดลบจะใช้ HEX4 เป็นขีดลบ จึงมีพื้นที่ 4 หลักสำหรับค่าลบ และ 5 หลักสำหรับค่าบวก ผลที่ไม่สามารถแสดงได้จะแสดง `FFFFFF`.

สำหรับหาร ใช้ HEX4:3 แสดงผลหาร (2 หลัก), HEX2 แสดงสามขีด, HEX1:0 แสดงเศษ (2 หลัก), HEX5 เป็นเครื่องหมาย `d` หรือ `-` ถ้าผลหารติดลบ หากเศษติดลบจะเปิด **จุดทศนิยมของ HEX1** เพื่อระบุเครื่องหมายลบของเศษ (เป็นข้อตกลงการแสดงผลที่เพิ่มเอง เนื่องจากพื้นที่จำกัด)

**การสั่ง Compile:** File > Open Project > เลือก `.qpf` > Processing > Start Compilation แล้วตรวจสอบ Error ก่อน Tools > Programmer เพื่อโปรแกรมไฟล์ `.sof` ที่ Quartus สร้างขึ้น (ไฟล์ ZIP นี้ไม่มี `.sof` สำเร็จรูป)

**การจำลอง:** เปิดไฟล์ในโฟลเดอร์ `sim/`; มี Testbench สำหรับ Controller, ปุ่ม KEY1 และจอ HEX ใช้งาน GHDL หรือ ModelSim ได้ สคริปต์ `sim/run_ghdl.sh` เตรียมไว้สำหรับเครื่องที่มี GHDL ติดตั้ง

**สถานะการตรวจสอบ:** ผ่านการตรวจสอบโครงสร้างไฟล์/Pin และชุดทดสอบอัลกอริทึม BCD ด้วย Python แล้ว แต่ **ยังไม่ได้ Compile/Synthesize หรือรัน Testbench VHDL ด้วย Quartus/GHDL จริง** โปรดทดสอบก่อนนำไปส่งงาน
